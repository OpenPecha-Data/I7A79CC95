## Title
	- ༄༅། །ལྕེ་བཙུན་སྙིང་ཐིག་གི་ཆོས་སྐོར།
	- ༄༅། །ཛྙཱནཾསུཔནཱིཨབྷིརསཱཙིཏྟཾཏིལཔུརགཏིབཙཔཋབིཧརཏིསྨ།།
	- ༄༅། །གུཧྱཨརྠསམུཌཙརལེཁཤཱཥཛྙཱནཾསུཔཐཾབིཧརཏིསྨ།། །།
	- ༄༅། །མཧཱསནྡྷིཨབྷིརསཙིཏྟཾཏིལཀཱབྷིཥིཏབིདྷོམྲྀཏཾནོབྲྀཥྜིཏིསྨ།།
	- ༄༅། །མཧཱསནྡྷིཙིཏྟཏིལཀཔུརགཏིནིཏལེཁཱབྷིརསབིདྱཱདྷརཏུཎྜཾཏིབརྠཾནམཱསྟི། །།
